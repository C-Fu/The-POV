## 5-minute quickstart

```bash
# 1. Install Node.js LTS from https://nodejs.org  (verify:)
node -v
# 2. Install OpenCode (macOS shown; Windows options in INSTALL.md)
curl -fsSL https://opencode.ai/install | bash
# 3. Install GSD
npx gsd-opencode
# 4. Start: run `opencode` in your project, then /connect and /gsd-new-project
```
