## Panduan pantas 5 minit

```bash
# 1. Pasang Node.js LTS dari https://nodejs.org  (semak:)
node -v
# 2. Pasang OpenCode (macOS ditunjukkan; pilihan Windows dalam INSTALL.ms-MY.md)
curl -fsSL https://opencode.ai/install | bash
# 3. Pasang GSD
npx gsd-opencode
# 4. Mula: jalankan `opencode` dalam projek anda, kemudian /connect dan /gsd-new-project
```
